## What changed

1. **Choosing the day's frame planter no longer rewrites a losing candidate's watch report**
   (`Evil.plan_daily_frame`). Scoring each evil member used to edit an untold Night Watch
   report in place, so Lian's report changed though Dorian won the slot. Now a candidate only
   marks that its report would be rewritten. The rewrite happens for the chosen member alone,
   and is logged as a lie with the old text.
2. **A Monitor bluffer is never given a window sighting to tell.** Both of the planter's window
   branches (the death block, and "leaving home") now check the planned bluff: no Monitor sees
   from its window (`monitor.gd`). The neighbour's "saw them go in" (`world_night.gd`) now skips
   a real Monitor and a Monitor bluffer too, as the street-sighting window already did.
3. **A planted sighting is logged as a lie when first told** (`Evil.fake_night_sighting`), once.
   It came from the plan's cache, which skipped the lie log, so `grimoire lies` missed
   Dorian's and Odette's. A sighting made up there, and logged already, isn't logged twice.
4. **A hint pressed at the meeting lists only gifts on the script** (`mind_podium.gd`), using
   `C.package_roles_text`, as the conversation hint does. The fact's `roles` keep the whole
   family for the Workshop. Herald agreed this one is mine.
