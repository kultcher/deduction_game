# Visual novel cast portraits

Generated in three batches with the built-in image generation tool from the existing character portraits. These portraits are used in the daytime conversation view. Each original portrait is the identity and style reference for its corresponding new portrait. Clothing below the original crop is a generated interpretation.

Batches: Dorian, Edda, Fenwick, Greta; Hollis, Isolde, Jory, Kiran; Lian, Merrin, Nisha, Odette.

## Prompt

Use case: identity-preserve. Create a large waist-up visual novel character portrait for Demonologist from the supplied original portrait. It must be recognizably the exact same character, not a redesign. Preserve their apparent age, face, skin tone, hairstyle and color, gaze, original expression, clothing, accessories, and original proportions. Extend the outfit naturally to waist length. Match the game's illustrated papercraft look exactly: hand-cut layered paper shapes, subtle warm paper grain, crisp dark ink contours, restrained flat cel shading, storybook texture. No 3D or glossy painting. Portrait-oriented 1024 x 1536 canvas, head in upper third, entire hair and shoulders inside canvas, character fills frame, lower torso cropped at bottom. Hands may remain out of view. Genuine transparent background, no text, frames, props or token base. Ignore tiny fragments of neighboring characters at the edges of the reference. One character only.

Each request additionally specified: “The supplied image is the authoritative reference for [character].”
